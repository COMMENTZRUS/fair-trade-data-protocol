# FTDP Solana Admin-Controlled Constant-Time Splitter (`admin-union`)

Dual-licensed **MIT OR Apache-2.0** (Fair Trade Data Protocol / Constant-Time MultiSplitter).

Splits incoming SOL among **unlimited shareholders in constant time ($O(1)$)** with admin-controlled contribution weights (`initialize`, `add_user`, `modify_shares`, `withdraw`, `transfer_ownership`).
