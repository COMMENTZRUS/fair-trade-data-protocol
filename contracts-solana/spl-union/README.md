# FTDP Solana Token-2022 Transfer-Hook Constant-Time Splitter (`spl-union`)

Dual-licensed **MIT OR Apache-2.0** (Fair Trade Data Protocol / Constant-Time MultiSplitter).

Splits incoming SOL and SPL tokens (e.g., USDC, FTD) among **unlimited Token-2022 share holders in constant time ($O(1)$)** via automatic transfer-hook accrual (`initialize`, `register`, `withdraw`, `initialize_extra_account_meta_list`, `transfer_hook`).
